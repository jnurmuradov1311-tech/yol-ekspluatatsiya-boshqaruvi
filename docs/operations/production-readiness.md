# Ishlab chiqarishga chiqarish darvozalari

Kodning mavjudligi ishlab chiqarishga tayyorlik degani emas. Quyidagi darvozalar dalil bilan yopiladi:

- [ ] Yo'l ta'mirlash punkti sandbox contract testi o'tdi.
- [ ] RoadVision natija payloadi va withdrawal/revision testi o'tdi.
- [ ] IQN katalogi hamda nuqson–ish mappingi soha egasi tomonidan tasdiqlandi.
- [ ] Supabase ishlab chiqarish loyihasi, PITR va restore drill tekshirildi.
- [ ] PHP API, worker va scheduler konteyner hostida health checkdan o'tdi.
- [ ] Vercel candidate artifact E2E testdan keyin promote qilindi.
- [ ] Unitlararo ruxsat, IDOR va ombor/texnika race-condition testlari o'tdi.
- [ ] UAT road-unit boshlig'i, dispetcher, omborchi va qabul inspektori bilan imzolandi.
- [ ] Maxfiy kalitlar repo va frontend bundle ichida yo'qligi tasdiqlandi.
- [ ] RPO/RTO va rollback amalda sinovdan o'tdi.
