## Calculation semantics for the system
- Let `Q` be actual/planned work volume and `B` the norm base quantity contained in the measurement unit (e.g. 100 m² or 1000 m²). Scaling factor: `F = Q / B`.
- Required builder-worker person-hours = `F × worker_person_hours_norm`.
- Required machine-operator person-hours = `F × operator_person_hours_norm`.
- Required machine-hours per machine = `F × machine_hour_norm`.
- Required material quantity per material = `F × material_quantity_norm`.
- Direct monthly cost = `Σ(person-hours × effective hourly tariff) + Σ(material qty × effective unit price) + Σ(machine-hours × effective machine-hour price)`.
- Avoid double-counting machine-operator labor: machine-hour tariffs need an explicit `includes_operator_wage` flag; if true, exclude operator labor from the separate labor subtotal.
- Recurrence appendix values are approximately reciprocal (`annual frequency ≈ 1 / recurrence interval`, subject to source rounding). Annual planned quantity derives from maintained asset quantity × frequency, then is distributed by season/month.
- IQN 02-24 contains resource quantities, not market/payroll prices. Wage tariffs, material prices, and machine-hour rates require separately versioned price lists with effective dates.

## Recommended domain model
- `norm_documents`: code, edition, effective dates, approval metadata, source hash, status.
- `work_categories` + `work_types`: hierarchical general topics for defect capture; granular variants are selected only during planning.
- `time_norms`: source table/row, raw/canonical code, parent row, base quantity/unit, person-hours, basis reference, normalization status.
- `recurrence_rules`: work type, maintained-asset unit, interval/frequency, seasonal applicability.
- `resource_norms` + `resource_norm_variants`: work composition, base quantity/unit, raw/canonical code, source lineage, validation status.
- `resources`: labor role / machine / material, raw code, canonical code, name, unit; plus alias table for code/name spelling variants.
- `resource_norm_lines`: variant × resource × quantity per base unit.
- `price_lists` + versioned `price_items`: hourly labor tariff, material unit price, machine-hour price, currency, validity period, source, includes-operator flag.
- `work_orders`/`work_order_items`: origin defect or recurring plan, location, norm snapshot, planned resources/cost.
- `work_executions`: actual quantity, crew/timesheet, material issue, machine log, evidence, completion/approval.
- `monthly_acts`/`monthly_act_lines`: freeze execution, norm and price snapshots; calculate labor/material/machine subtotals and total; support approval and Excel export.
- `source_import_issues`: collision/mismatch/parse warning with reviewer and resolution, required for the anomalies above.
