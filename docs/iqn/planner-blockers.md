# Rejalashtiruvchi blocker katalogi

Har tanlangan yozuv `SCHEDULED` yoki bir/nechta blocker bilan `BLOCKED` bo'ladi. Umumiy “AI rejalashtira olmadi” xabari taqiqlangan.

| Kod | Ma'nosi | Tuzatish egasi |
|---|---|---|
| `FINDING_NOT_VERIFIED` | AI kuzatuvi hali tasdiqlanmagan | Inspektor |
| `ROAD_MAPPING_MISSING` | Yo'l/geometriya manbaga moslanmagan | Integratsiya admini |
| `NO_ACTIVE_UNIT_ASSIGNMENT` | Sana uchun yo'l bo'limi birikmasi yo'q | Manba tizim egasi |
| `IQN_MAPPING_MISSING` | Nuqson–ish crosswalk yo'q | Soha egasi |
| `IQN_VARIANT_UNDETERMINED` | Variant shartlari yetishmaydi | Planner/inspektor |
| `IQN_VARIANT_NOT_APPROVED` | Norma ko'rikdan o'tmagan | Soha egasi |
| `QUANTITY_MISSING` | Hajm uchun o'lchov yo'q | Inspektor |
| `UNIT_INCOMPATIBLE` | Birlik dimensioni mos emas | Norma administratori |
| `WORK_TEMPLATE_MISSING` | Brigada/resurs retsepti yo'q | Soha egasi |
| `REQUIRED_SKILL_MISSING` | Malakali xodim yo'q | Bo'lim boshlig'i |
| `WORKER_HOURS_INSUFFICIENT` | 420 daqiqalik limit ichida joy yo'q | Dispetcher |
| `EQUIPMENT_UNAVAILABLE` | Soz va bo'sh texnika yo'q | Mexanik |
| `OPERATOR_UNAVAILABLE` | Ruxsatli operator yo'q | Bo'lim boshlig'i |
| `MATERIAL_SHORTAGE` | Band qilinmagan stock yetmaydi | Omborchi |
| `SAFETY_EQUIPMENT_SHORTAGE` | Belgi/konus/to'siq yetmaydi | Omborchi/xavfsizlik |
| `TRAFFIC_CONTROL_PLAN_MISSING` | Tasdiqlangan ish zonasi sxemasi yo'q | Xavfsizlik xodimi |
| `ROAD_ZONE_CONFLICT` | Piket/yo'nalish/sanada to'qnashuv | Dispetcher |
| `PERMIT_REQUIRED` | Yopish/cheklash ruxsati yo'q | Tasdiqlovchi |
| `SOURCE_DATA_STALE` | Reconciliation muddati o'tgan | Integratsiya admini |
